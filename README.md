# CASE CLOSED 🕵️

## Game Description

Case Closed is a memory matching game where players
act as detectives trying to solve a mystery.

The game has 12 hidden evidence cards (6 matching pairs).
Players must find all matching pairs within 15 attempts
to solve the case.

## How to Play

1. Click Start Game to begin.
2. The player will see 12 face-down evidence cards.
3. Click two cards to reveal their symbols.
4. If the cards match, they stay face up.
5. If they do not match, they flip back.
6. Each two-card guess counts as one attempt.
7. Find all 6 pairs before running out of attempts.

## Win Condition

The player wins by matching all 6 pairs within
15 attempts.

The message "CASE SOLVED!" will appear.

## Loss Condition

The player loses if all 15 attempts are used
before finding all 6 pairs.

The message "CASE UNSOLVED!" will appear.
